  所以按鈕要加在「模板」裡，不是加在 index.html，這樣才不會被蓋掉。

做法：打開  templates/brief.html ，把下面【整段】複製，
      貼到該檔最底部的  </body>  之前，存檔、commit 即可。

不用動：那支 .py 程式完全不必修改，所有功能、流程、評分邏輯都不受影響。
特性：純附加。不修改、不刪除模板裡原本任何的 HTML / CSS / JS。
      樣式與 id 都加了 cmhx- 前綴，不會和現有的衝突。

----------------------------------------------------------------
為什麼貼在 templates/brief.html 而不是 index.html？
----------------------------------------------------------------

  render_html() 會用 templates/brief.html 算出 index.html，
  每天排程跑一次就覆蓋一次 index.html。
  → 貼在 index.html：明天重生後按鈕消失。
  → 貼在 templates/brief.html：每天重生都自動帶上按鈕，永久有效。

  這段是純靜態 HTML（沒有 {{ }} Jinja 語法），放進模板不會干擾
  原本的迴圈與變數，那支 .py 程式一行都不用改、功能不受影響。

----------------------------------------------------------------
archive.html 放哪？
----------------------------------------------------------------

  放在「index.html 與那些 YYYY-MM-DD.json 對外被瀏覽到的同一層」
  （GitHub Pages 的根目錄，也就是你 repo 首頁看到 index.html 的那層）。
  archive.html 是獨立靜態檔，不會被 Python 重生流程影響。
